# 关于这里

这里是梁梦磊的个人记录。

它不承担学术主页的职责，也不试图把每篇文章写成教程或结论。月记、生活、阅读、音乐、软件、设计和技术探索，都可以在这里留下来。

我希望它更像一个持续生长的私人空间：诚实，但仍然经过选择；自由，但不必杂乱。
